၁။ သဘောတူညီချက်

ရွှေဥ (ShweU) ကို download သို့မဟုတ် အသုံးပြုခြင်းဖြင့် ဤစည်းကမ်းများနှင့် ကိုယ်ရေးအချက်အလက် မူဝါဒ ကို သဘောတူပါသည်။ သဘောမတူပါက app ကို မသုံးပါနှင့်။ ရွှေဥကို BLAKE (developer) က ပေးသည်။

၂။ အသက်နှင့် အကောင့်

  • အသက် ၁၃ နှစ်နှင့်အထက် ဖြစ်ရမည် (သင့်နိုင်ငံ၏ ဥပဒေအရ လိုအပ်ပါက မိဘ / အုပ်ထိန်းသူ ခွင့်ပြုချက်ဖြင့်)။
  • စကားဝှက်ကို လျှို့ဝှက်ထားပါ။ အကောင့်ပေါ်ရှိ လှုပ်ရှားမှုအားလုံးအတွက် သင့်တွင် တာဝန်ရှိပြီး မှန်ကန်သော အချက်အလက် ပေးရမည်။
  • အကောင့်အမျိုးအစားများ — User၊ Creator၊ Shop နှင့် Admin။ အားလုံး ဓာတ်ပုံနှင့် ဗီဒီယို post တင်နိုင်သည်။ ဆောင်းပါးကို Creator၊ Shop နှင့် Admin များသာ ရေးနိုင်ပြီး admin မဟုတ်သူ၏ ဆောင်းပါးများကို ထုတ်ပြန်မီ admin က စိစစ်သည်။
  • App ထဲတွင် Creator သို့မဟုတ် Shop အကောင့်အတွက် လျှောက်ထားနိုင်သည်။ တင်သွင်းသည်များ မှန်ကန်ပြီး သင်ပိုင်ဆိုင်သည့်အရာ ဖြစ်ရမည်။ Admin များက အတည်ပြု သို့မဟုတ် ငြင်းပယ်နိုင်ပြီး နောက်ပိုင်း ပြန်ရုပ်သိမ်းနိုင်သည်။
  • Verified အမှတ်အသားကို admin က Creator / Shop အတည်ပြုချက်နှင့် သီးခြား ပေးပြီး အချိန်မရွေး ပြန်ရုပ်သိမ်းနိုင်သည်။

၃။ ရွှေဈေးနှင့် အကြောင်းအရာ

  • ဆောင်းပါး၊ ဈေးနှုန်း၊ အလေးချိန် အချက်အလက်၊ ရွှေတွက်စက်နှင့် အသုံးပြုသူ post များသည် ယေဘုယျ ကိုးကားရန်နှင့် ပညာပေးရန်သာ ဖြစ်ပြီး ငွေကြေး၊ ရင်းနှီးမြှုပ်နှံမှု သို့မဟုတ် ကုန်သွယ်မှု အကြံပြုချက် မဟုတ်ပါ။
  • ဈေးနှုန်းများသည် ညွှန်ပြချက်သာ ဖြစ်သည် (ကမ္ဘာ့ spot ဈေးကို gold-api.com နှင့် Binance public data မှ ရယူသည်)။ နှောင့်နှေးနိုင်၊ မှားယွင်းနိုင်ပြီး ပြည်တွင်းဆိုင်ဈေးနှင့် ပဲရည်နှင့် ကွာခြားနိုင်သည်။ ရောင်းဝယ်မီ ယုံကြည်ရသော ဆိုင်နှင့် အတည်ပြုပါ။
  • ရွှေတွက်စက် ရလဒ်များသည် သင်ထည့်သော ဂဏန်းများမှ သင့်ဖုန်းပေါ်တွင် တွက်ချက်သော ခန့်မှန်းချက်များသာ ဖြစ်သည်။
  • ရွှေဥသည် ရွှေ မရောင်း မဝယ်ပါ၊ ဆိုင်များကို အာမမခံပါ။ အသုံးပြုသူများကြား ရောင်းဝယ်မှုသည် ၎င်းတို့၏ တာဝန်သာ ဖြစ်သည်။

၄။ သင့်အကြောင်းအရာ

  • သင်တင်သော အကြောင်းအရာကို သင်ပိုင်ဆိုင်သည်။ App ထဲတွင် သင်ရွေးသော မြင်နိုင်မှုအတိုင်း သိမ်းဆည်း၊ ပြသရန် ကမ္ဘာတစ်ဝှမ်း၊ အခကြေးငွေမဲ့၊ သီးသန့်မဟုတ်သော လိုင်စင်ကို ကျွန်ုပ်တို့အား ပေးသည်။ သင်ဖျက်သည့်အခါ လိုင်စင် ရပ်ဆိုင်းသည် (ကိုယ်ရေးအချက်အလက် မူဝါဒတွင် ဖော်ပြထားသည့်အတိုင်း backup တွင် အချိန်အကန့်အသတ်ဖြင့် ကျန်သော မိတ္တူများမှအပ)။
  • သင်တင်သည်များကို တင်ပိုင်ခွင့် ရှိကြောင်း အာမခံသည်။

၅။ တားမြစ်ထားသော အကြောင်းအရာ (လုံးဝ သည်းမခံ)

ရွှေဥသည် မသင့်လျော်သော အကြောင်းအရာနှင့် အနိုင်ကျင့်သော အသုံးပြုသူများကို လုံးဝ သည်းမခံပါ။ အောက်ပါတို့ကို မတင်ရ၊ မလုပ်ရ —

  • အမုန်းစကား၊ ခွဲခြားဆက်ဆံမှု၊ အကြမ်းဖက်မှု ခြိမ်းခြောက်ခြင်း၊ နှောင့်ယှက်ခြင်း သို့မဟုတ် အနိုင်ကျင့်ခြင်း။
  • လိင်ပိုင်းဆိုင်ရာ သို့မဟုတ် ညစ်ညမ်းသော အကြောင်းအရာ၊ ကလေးများကို အန္တရာယ်ပြု သို့မဟုတ် အမြတ်ထုတ်သော အကြောင်းအရာ မည်သည့်ပုံစံမဆို။
  • လိမ်လည်မှု၊ အတု သို့မဟုတ် ခိုးယူထားသော ရွှေ၊ ပဲရည် သို့မဟုတ် အလေးချိန် မမှန်မကန် ဖော်ပြခြင်း၊ ငွေလိမ်လည်မှု၊ pyramid နှင့် စျေးကွက်ခြယ်လှယ်မှု။
  • အခြားသူ၏ ကိုယ်ရေးအချက်အလက်ကို ခွင့်မပြုဘဲ ထုတ်ဖော်ခြင်း သို့မဟုတ် အခြားသူ အယောင်ဆောင်ခြင်း။
  • တရားမဝင် လုပ်ဆောင်ချက်၊ မူပိုင်ခွင့် ချိုးဖောက်မှု၊ spam သို့မဟုတ် malware။
  • App ကို hack၊ scrape သို့မဟုတ် ပြောင်းပြန် အင်ဂျင်နီယာ လုပ်ခြင်း။

၆။ Report၊ Block နှင့် စိစစ်မှု

  • Post၊ ဆောင်းပါး၊ Spark၊ မှတ်ချက် သို့မဟုတ် အသုံးပြုသူကို "Report" ဖြင့် အမျိုးအစားနှင့် အသေးစိတ် ထည့်၍ တိုင်ကြားနိုင်သည်။
  • အသုံးပြုသူကို block လုပ်ပါက နှစ်ဦးကြား အကြောင်းအရာ၊ link နှင့် follow များကို ဖျောက်ထားမည်။ Settings → ပိတ်ဆို့ထားသော အသုံးပြုသူများ တွင် စီမံနိုင်သည်။
  • Report များကို နေ့စဉ် စိစစ်ပြီး ၂၄ နာရီအတွင်း ဆောင်ရွက်သည် — စည်းကမ်း ချိုးဖောက်သော အကြောင်းအရာကို ဖယ်ရှားပြီး တင်သူကို ပိတ်ပင်သည်။ ပိတ်ပင်ခံထားရသူသည် post၊ မှတ်ချက်၊ reaction၊ follow နှင့် report မလုပ်နိုင်ပြီး ၎င်း၏ post များကို ဖျောက်ထားနိုင်သည်။
  • ဆောင်းပါးများကို ထုတ်ပြန်မီ စိစစ်နိုင်သည်။ မည်သည့် အကြောင်းအရာကိုမဆို ကြိုတင်အသိပေးချက်မရှိဘဲ ဖယ်ရှား သို့မဟုတ် ကန့်သတ်နိုင်သည်။
  • ပိတ်ပင်ခံထားရသော အကောင့်ကို ဖျက်ပါက တူညီသော အီးမေးလ်ဖြင့် အကောင့်အသစ်ကိုလည်း ပိတ်ပင်နိုင်ရန် အီးမေးလ်၏ one-way hash ကို ဆက်ထားသည်။ ပိတ်ပင်မှုကို ရှောင်ရန် အကောင့်အသစ် ဖွင့်ခြင်းကို ခွင့်မပြုပါ။
  • တရားမဝင် အကြောင်းအရာကို ချက်ချင်း ဖျောက်ပြီး အကောင့်ကို ပိတ်ပင်ကာ ဥပဒေအရ ထိန်းထားနိုင်သည်။ အာဏာပိုင်ထံ တိုင်ကြားနိုင်သည်။
  • ပိတ်ပင်မှုကို ပြန်လည်သုံးသပ်စေလိုပါက ၃၀ ရက်အတွင်း blake@shweu.app သို့ email ပို့ပါ — ၇ ရက်အတွင်း ပြန်ကြားပါမည်။

၇။ လိုင်စင် (EULA)

  • ရွှေဥကို သင့်အား ရောင်းချခြင်း မဟုတ်ဘဲ လိုင်စင်ပေးခြင်း ဖြစ်သည် — Apple Media Services Terms ၏ Usage Rules အတိုင်း သင်ပိုင်ဆိုင် သို့မဟုတ် ထိန်းချုပ်သော Apple စက်များတွင် သုံးရန် ကန့်သတ်ထားသော၊ လွှဲပြောင်း၍ မရသော လိုင်စင်။
  • ဤလိုင်စင်သည် သင်နှင့် developer ကြားတွင်သာ ဖြစ်ပြီး Apple နှင့် မဟုတ်ပါ။ App နှင့် ၎င်း၏ အကြောင်းအရာအတွက် developer တွင်သာ တာဝန်ရှိသည်။
  • Apple သည် app အတွက် ပြုပြင်ထိန်းသိမ်းမှု သို့မဟုတ် support ပေးရန် တာဝန်မရှိပါ။
  • App သည် သက်ဆိုင်ရာ အာမခံချက်နှင့် မကိုက်ညီပါက Apple ထံ အသိပေး၍ ဝယ်ယူငွေ (ရှိပါက) ပြန်ရနိုင်သည်။ ဥပဒေခွင့်ပြုသည့် အတိုင်းအတာအထိ Apple တွင် အခြား အာမခံတာဝန် မရှိပါ။
  • ထုတ်ကုန်တာဝန်၊ ဥပဒေလိုက်နာမှု၊ စားသုံးသူ အကာအကွယ် တိုင်ကြားမှုများနှင့် ပြင်ပ ဉာဏပစ္စည်း တိုင်ကြားမှုများကို Apple မဟုတ်ဘဲ developer က ကိုင်တွယ်သည်။
  • သင်သည် အမေရိကန် ပိတ်ဆို့ထားသော နိုင်ငံတွင် မနေထိုင်ကြောင်းနှင့် ကန့်သတ်စာရင်းဝင် မဟုတ်ကြောင်း အာမခံသည်။
  • Apple နှင့် ၎င်း၏ လက်အောက်ခံ ကုမ္ပဏီများသည် ဤလိုင်စင်၏ ပြင်ပ အကျိုးခံစားခွင့်ရှိသူများ ဖြစ်ပြီး သင့်အပေါ် အကောင်အထည်ဖော်ပိုင်ခွင့် ရှိသည်။
  • သက်ဆိုင်ရာ ပြင်ပ စည်းကမ်းများ (ဥပမာ — mobile ဝန်ဆောင်မှုပေးသူ၏) ကို လိုက်နာရမည်။

၈။ ဉာဏပစ္စည်း

ရွှေဥ အမည်၊ logo၊ ဒီဇိုင်းနှင့် software ကို developer က ပိုင်ဆိုင်သည်။

၉။ ရပ်စဲခြင်း

အကောင့်ကို အချိန်မရွေး ဖျက်နိုင်သည် (Settings → အကောင့်ဖျက်မည်၊ "DELETE" ရိုက်ပြီး စကားဝှက် ထည့်ပါ)။ ဖျက်သည့်အရာများကို ကိုယ်ရေးအချက်အလက် မူဝါဒတွင် ဖော်ပြထားသည်။ ဤစည်းကမ်း ချိုးဖောက်သော အကောင့်များကို ကြိုတင်အသိပေးချက် မရှိဘဲ ဆိုင်းငံ့ သို့မဟုတ် ပိတ်နိုင်သည်။

၁၀။ အာမခံချက် ငြင်းဆိုခြင်းနှင့် တာဝန်

  • App ကို "ရှိသည့်အတိုင်း" နှင့် "ရရှိနိုင်သည့်အတိုင်း" ပေးပြီး မည်သည့် အာမခံချက်မျှ မပေးပါ။ အမြဲ အလုပ်လုပ်မည် သို့မဟုတ် အမှားကင်းမည်ဟု ကတိ မပေးနိုင်ပါ။
  • အသုံးပြုသူ အကြောင်းအရာ၊ ဆိုင်များ သို့မဟုတ် အသုံးပြုသူများကြား ရောင်းဝယ်မှုအတွက် ကျွန်ုပ်တို့ တာဝန်မရှိပါ။
  • ဥပဒေခွင့်ပြုသည့် အတိုင်းအတာအထိ app အသုံးပြုမှုမှ ဖြစ်ပေါ်သော တိုက်ရိုက်မဟုတ်သော၊ မတော်တဆ သို့မဟုတ် နောက်ဆက်တွဲ ဆုံးရှုံးမှုများ၊ ရွှေ ရောင်းဝယ်ရေး ဆုံးဖြတ်ချက်များမှ ဆုံးရှုံးမှုများအတွက် တာဝန်မရှိပါ။ ဥပဒေအရ ကန့်သတ်၍ မရသော တာဝန်များကို ဤစည်းကမ်းက မကန့်သတ်ပါ။

၁၁။ အုပ်ချုပ်သည့် ဥပဒေ

ဤစည်းကမ်းများကို ထိုင်းနိုင်ငံ ဥပဒေများဖြင့် အုပ်ချုပ်သည်။ သင်နေထိုင်သော နိုင်ငံ၏ ဥပဒေအရ သင်ရရှိသော စားသုံးသူ အကာအကွယ်များကို မထိခိုက်ပါ။
