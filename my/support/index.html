အကူအညီ

ပုံမှန်အားဖြင့် ၇ ရက်အတွင်း ပြန်ကြားပါသည်။

ဆက်သွယ်ရန်

support@shweu.app သို့ email ပို့ပါ သို့မဟုတ် app ထဲမှ — Profile → Settings → ဆက်သွယ်ရန်။

အကောင့် ဖျက်နည်း

Profile → Settings → အကောင့်ဖျက်မည် → DELETE ဟု ရိုက်ပြီး စကားဝှက် ထည့်ပါ။ သင့်အကောင့်၊ post များ၊ ဓာတ်ပုံ၊ ဗီဒီယိုနှင့် ဖိုင်များကို ဖျက်ပါမည်။ အသေးစိတ်ကို ကိုယ်ရေးအချက်အလက် မူဝါဒ တွင် ကြည့်ပါ။

Report နှင့် Block

Post၊ မှတ်ချက် သို့မဟုတ် ပရိုဖိုင်ပေါ်ရှိ … ကို နှိပ်ပြီး Report သို့မဟုတ် Block ကို ရွေးပါ။ Report များကို admin က နေ့စဉ် စိစစ်ပါသည်။ Block ထားသူ၏ အကြောင်းအရာကို မမြင်ရတော့ပါ။ Settings → ပိတ်ဆို့ထားသော အသုံးပြုသူများ တွင် ပြန်ဖွင့်နိုင်ပါသည်။

အန္တရာယ်ရှိသော သို့မဟုတ် တရားမဝင်သော အကြောင်းအရာ တွေ့ပါက app ထဲတွင် report လုပ်ပြီး email ပါ ပို့ပါ။

စကားဝှက် မေ့သွားလျှင်

Sign in မျက်နှာပြင်တွင် စကားဝှက် မေ့နေပါသလား? ကို နှိပ်ပါ — စကားဝှက်အသစ် ထည့်ရန် link ကို email ဖြင့် ပို့ပေးပါမည်။

ပိတ်ပင်ခံရပါသလား

ပြန်လည်သုံးသပ်စေလိုပါက ၃၀ ရက်အတွင်း သင့်အကောင့်၏ email မှ support@shweu.app သို့ ပို့ပါ။ ၇ ရက်အတွင်း ပြန်ကြားပါမည်။

ကျွမ်းကျင်သူ (ဖန်တီးသူ သို့မဟုတ် လုပ်ငန်း) ဖြစ်ရန်

Profile → Settings → ဖန်တီးသူ သို့မဟုတ် လုပ်ငန်း ဖြစ်ရန်။ အတည်မပြုမီ စစ်ဆေးသည်များ —

  • ဖန်တီးသူ — ကိုယ့်နယ်ပယ်တွင် အတွေ့အကြုံ (ယခင်လက်ရာ၊ လက်မှတ် သို့မဟုတ် social စာမျက်နှာ) နှင့် ကိုယ်တိုင် ဖန်တီးထားသော content ကိုသာ တင်ခြင်း။
  • လုပ်ငန်း — လုပ်ငန်း တကယ်ရှိကြောင်း (ဆိုင် သို့မဟုတ် လုပ်ငန်း ဓာတ်ပုံ နှင့် လိုင်စင် သို့မဟုတ် လုပ်ငန်း စာမျက်နှာ link) နှင့် ဆက်သွယ်၍ရသော ဖုန်းနံပါတ်။
  • အားလုံး — ShweU စည်းကမ်းများ။ အတု သို့မဟုတ် လှည့်စားသော ကမ်းလှမ်းချက် မတင်ရ။

စီမံသူက ၇ ရက်အတွင်း ဆုံးဖြတ်ပါမည်။

ကျွမ်းကျင်သူ၊ ရှာဖွေ နှင့် စိတ်ကြိုက်

ပို့စ်များတွင် — ကျွမ်းကျင်သူ သည် အတည်ပြုထားသော ဖန်တီးသူနှင့် လုပ်ငန်းများ၏ ပို့စ်များ၊ ရှာဖွေ သည် လူတိုင်း၏ ပို့စ်များ၊ စိတ်ကြိုက် သည် သင် စိတ်ကြိုက်ထဲ ထည့်ထားသော အကောင့်များ၏ ပို့စ်များကို ပြသည်။ ကျွမ်းကျင်သူများကို ရွှေဥက ထောက်ခံခြင်း မဟုတ်ပါ (စည်းကမ်း ၃ ကို ကြည့်ပါ)။

ရွှေဈေး
