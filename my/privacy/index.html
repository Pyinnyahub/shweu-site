၁။ ကျွန်ုပ်တို့ အကြောင်း

ရွှေဥ (ShweU) သည် ရွှေ၊ ကျောက်မျက်နှင့် လက်ဝတ်ရတနာအကြောင်း မြန်မာ/အင်္ဂလိပ် နှစ်ဘာသာ ဗဟုသုတနှင့် community app ဖြစ်သည်။ BLAKE က လည်ပတ်ပြီး app ထဲရှိ သင့်အချက်အလက်အတွက် တာဝန်ယူသည်။ ဆက်သွယ်ရန် — blake@shweu.app။

၂။ စုဆောင်းသော အချက်အလက်

အကောင့်

  • အီးမေးလ်လိပ်စာနှင့် စကားဝှက် (Supabase Auth တွင် hash ပြုလုပ်၍ သိမ်းသည်)၊ အသုံးပြုသူ ID နှင့် login session token များ။

ပရိုဖိုင် (အများပြည်သူ မြင်နိုင်သည်)

  • ပြသမည့်အမည်၊ ကိုယ်ရေးအကျဉ်း၊ ပရိုဖိုင်ပုံ၊ cover ပုံ၊ အခန်းကဏ္ဍ (user / creator / ဆိုင်ပိုင်ရှင် / admin)၊ verified အမှတ်အသားနှင့် အကောင့်ဖွင့်သည့်ရက်။
  • ဆိုင်ပိုင်ရှင်များအတွက် — ဆိုင်အမည်၊ မြို့၊ ဖုန်း၊ Viber၊ Telegram၊ Messenger link၊ မြေပုံ link၊ အမျိုးအစားနှင့် ဆိုင်ပစ္စည်းပုံများ။
  • ပရိုဖိုင် link များ (အများဆုံး ၅ ခု) — Facebook၊ TikTok၊ YouTube၊ Telegram၊ Viber၊ website၊ ဖုန်းနံပါတ်၊ မြေပုံ။ ဖုန်းနံပါတ် အပါအဝင် ဤ link များကို အခြားအသုံးပြုသူများ မြင်နိုင်သည်။

သင်တင်သော အကြောင်းအရာ

  • Post များ၊ ဆောင်းပါးများ (မြန်မာ/အင်္ဂလိပ် ခေါင်းစဉ်နှင့် စာသား၊ ခေါင်းစဉ်အမျိုးအစား)၊ Sparks ဗီဒီယိုနှင့် thumbnail၊ ဓာတ်ပုံများ၊ repost များ၊ မှတ်ချက်နှင့် ပြန်စာများ။
  • Post မြင်နိုင်မှု (အများပြည်သူ / Follower များ / ကိုယ်တိုင်သာ)။ ဆောင်းပါးများသည် အမြဲ အများပြည်သူ မြင်နိုင်ပြီး admin စိစစ်မှု ရှိနိုင်သည်။
  • Photos picker မှ သင်ရွေးသော ဓာတ်ပုံ/ဗီဒီယိုများသာ upload လုပ်သည်။ သင့် photo library တစ်ခုလုံးကို မဝင်ရောက်ပါ။

လှုပ်ရှားမှု

  • Reaction၊ follow နှင့် favorite၊ သိမ်းထားသော post၊ block ထားသူများနှင့် သင်တင်သော report များ (အမျိုးအစား၊ အသေးစိတ် စာလုံး ၅၀၀ အထိ၊ စိစစ်မှုမှတ်တမ်း)။

Creator / ဆိုင် လျှောက်လွှာ

  • ပြသမည့်အမည်၊ ကိုယ်ရေးအကျဉ်း၊ နမူနာနှင့် အခြား link များ၊ ဆိုင်အမည်၊ မြို့၊ ဖုန်း၊ Viber / Telegram၊ မြေပုံ link နှင့် အထောက်အထားအဖြစ် upload လုပ်သော ဖိုင် အများဆုံး ၅ ခု (JPG၊ PNG သို့မဟုတ် PDF၊ တစ်ခုလျှင် 5 MB အထိ)။ Admin များက စိစစ်ပြီး ဆုံးဖြတ်ချက်နှင့် အကြောင်းပြချက်ကို မှတ်တမ်းတင်သည်။

စိစစ်မှု မှတ်တမ်း

  • Role နှင့် badge ပြောင်းလဲမှု မှတ်တမ်း၊ ပိတ်ပင်မှု၊ ဥပဒေအရ ထိန်းထားမှုနှင့် report များ။

အမှားနှင့် crash အစီရင်ခံစာ

  • App တွင် တစ်ခုခု မအောင်မြင်လျှင် (အမှား၊ crash၊ ရပ်တန့်သွားခြင်း သို့မဟုတ် iOS က ပြသော CPU / disk အသုံး အလွန်များခြင်း) app က အစီရင်ခံစာ အတိုတစ်ခု ပို့သည် — error code နှင့် စာတိုတစ်ကြောင်း၊ app နှင့် iOS version၊ အချိန်။ Sign in ဝင်ထားလျှင် သင့် user ID နှင့် ချိတ်သည်။ ပြဿနာ ပြင်ရန်သာ သုံးပြီး ၃၀ ရက် သိမ်းကာ ဖျက်သည်။ သင့် post၊ စာ၊ ဓာတ်ပုံ သို့မဟုတ် စကားဝှက် မပါပါ။

သင့်ဖုန်းပေါ်တွင်သာ သိမ်းသည်

  • App နှင့် ဆောင်းပါး ဘာသာစကား၊ ဖတ်ပြီးသော ဆောင်းပါးများ၊ မကြာသေးမီက ရှာဖွေမှုများနှင့် ရွှေတွက်စက် ဆက်တင်။ ရွှေတွက်စက်သည် သင့်ဖုန်းပေါ်တွင်သာ အလုပ်လုပ်ပြီး ထည့်သော ဂဏန်းများကို ကျွန်ုပ်တို့ထံ မပို့ပါ။

မစုဆောင်းသည်များ — တည်နေရာ (GPS)၊ အဆက်အသွယ်စာရင်း၊ ကြော်ငြာ ID (IDFA)၊ analytics၊ ငွေပေးချေမှု အချက်အလက်၊ ပြင်ပ crash reporting ဝန်ဆောင်မှု သို့မဟုတ် ကြော်ငြာအတွက် အချက်အလက်။

၃။ အသုံးပြုပုံ

  • အကောင့်၊ login နှင့် app ၏ လုပ်ဆောင်ချက်များ (feed၊ ပရိုဖိုင်၊ follow၊ မှတ်ချက်) ပေးရန်။
  • သင်တင်သော အကြောင်းအရာကို သင်ရွေးသော မြင်နိုင်မှုအတိုင်း ပြသရန်။
  • လုံခြုံရေးနှင့် စိစစ်မှု (filter၊ report၊ block၊ ပိတ်ပင်ခြင်း) အတွက်။
  • Creator / ဆိုင် လျှောက်လွှာများကို စိစစ်ရန်။
  • သင့်မေးမြန်းချက်များကို ဖြေကြားရန်။

သင့်အချက်အလက်ကို မရောင်းပါ၊ ကြော်ငြာအတွက် မသုံးပါ၊ app / website များကြား ခြေရာမခံပါ။ ထို့ကြောင့် App Tracking Transparency ခွင့်ပြုချက် မတောင်းပါ။

၄။ ပြင်ပ ဝန်ဆောင်မှုများ

  • Supabase — login၊ database နှင့် ဖိုင်သိမ်းဆည်းခြင်း။ သင့်အချက်အလက်ကို စင်ကာပူတွင် သိမ်းဆည်းပြီး လုပ်ဆောင်သည် (ap-southeast-1)။ supabase.com/privacy
  • gold-api.com နှင့် Binance public market data (data-api.binance.vision၊ api.binance.com) — ကမ္ဘာ့ရွှေဈေး ရယူရန်သာ။ ကိုယ်ရေးအချက်အလက် မပို့ပါ။ အခြား server များကဲ့သို့ သင့် IP address ကို မြင်နိုင်သည်။
  • သင်ဖွင့်သော profile link များ (Facebook၊ Telegram စသည်) သည် ထို site များ၏ ကိုယ်ပိုင်မူဝါဒ သက်ရောက်သည်။

၅။ မြင်နိုင်သူများ

  • အများပြည်သူ — ပရိုဖိုင်၊ ဆိုင်အချက်အလက်၊ profile link များ၊ အများပြည်သူ post / ဆောင်းပါး / မှတ်ချက်များနှင့် follower အရေအတွက်။ ပရိုဖိုင်ပုံများသည် အများပြည်သူ မြင်နိုင်သည်။ Post ဓာတ်ပုံ/ဗီဒီယိုများကို private storage တွင် သိမ်းပြီး ကြည့်ခွင့်ရှိသူများထံ သက်တမ်းတို link ဖြင့်သာ ပြသည်။
  • Admin များ — report များ၊ Creator / ဆိုင် လျှောက်လွှာများနှင့် စိစစ်ရန် လိုသော အကြောင်းအရာ။
  • လျှောက်လွှာဖိုင်များ သည် private ဖြစ်ပြီး သင်နှင့် admin များသာ မြင်နိုင်သည်။
  • အာဏာပိုင်များ — ဥပဒေအရ လိုအပ်မှသာ။

၆။ သိမ်းဆည်းခြင်းနှင့် ဖျက်ခြင်း

  • သင့်အကောင့် ရှိနေသမျှ အချက်အလက်ကို သိမ်းထားသည်။
  • App ထဲမှ ဖျက်ရန် — Settings → အကောင့်ဖျက်မည်၊ "DELETE" ရိုက်ပြီး စကားဝှက် ထည့်ပါ။ ပရိုဖိုင်၊ post၊ ဆောင်းပါး၊ Sparks၊ မှတ်ချက်၊ reaction၊ follow၊ သိမ်းထားသည်များ၊ block၊ link၊ ဆိုင်အချက်အလက်၊ လျှောက်လွှာများနှင့် upload လုပ်ထားသော ဖိုင်အားလုံး (ပရိုဖိုင်ပုံ၊ post ဓာတ်ပုံ/ဗီဒီယို၊ ဆိုင်ပစ္စည်းပုံ၊ လျှောက်လွှာ အထောက်အထားဖိုင်) ကို ဖျက်သည်။
  • သင်တင်ထားသော report များနှင့် role / badge ပြောင်းလဲမှု မှတ်တမ်းကို အမည်မဖော်ဘဲ (သင့် ID ဖယ်၍) ဆက်ထားနိုင်သည်။ အခြားသူများ repost လုပ်ထားသော သင့် post သည် "မရရှိနိုင်ပါ" ဟု ပြမည်။
  • ပိတ်ပင်ခံထားရသော အကောင့်ကို ဖျက်ပါက ထိုသူ ပြန်မဝင်နိုင်စေရန် အီးမေးလ်၏ one-way hash (အီးမေးလ်ကိုယ်တိုင် မဟုတ်) နှင့် ပိတ်ပင်မှု စည်းကမ်းချက်များကိုသာ ဆက်ထားသည်။
  • တရားမဝင် အကြောင်းအရာကြောင့် ဥပဒေအရ ထိန်းထားသော အကောင့်ဖြစ်ပါက ထိန်းထားသည့် ကာလအတွင်း (ပုံမှန် ၉၀ ရက်အထိ) ဖျက်ခြင်းကို နှောင့်နှေးမည် — အာဏာပိုင်ထံ အထောက်အထား ပေးနိုင်ရန်။
  • Encrypt လုပ်ထားသော backup များတွင် မိတ္တူများ အချိန်အကန့်အသတ်ဖြင့် ကျန်နိုင်သည်။ ၎င်းတို့ကို အသုံးမပြုပါ။
